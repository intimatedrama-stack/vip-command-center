# Product Spec: VIP Command Center

## Positioning

A private command center for scaling legal virtual content, VIP chat, video-chat offers, custom content, and recurring attention packages.

## Core Modules

1. CRM
2. Buyer scoring
3. Offer/menu generator
4. Follow-up engine
5. Posting-kit generator
6. Campaign tracking
7. Analytics dashboard
8. VIP retention engine

## Operating Principle

Do not sell random one-off content. Build controlled access, repeat spend, and buyer memory.

## V1 Dashboard Pages

- Leads
- Hot Leads
- Follow-Ups
- Campaign Posts
- Transactions
- Offers
- Metrics
- Prompt Runs

## V2 Features

- Content asset library
- AI media tagging
- Buyer preference memory
- A/B testing
- Landing page builder
- Stripe/payment-link metadata tracking
- Broadcast campaign drafts
